# Референсы для генерации картинок

Положите файлы-референсы в папку своего типа поста:

- `news/` — референсы для 📰 новостных постов
- `feature/` — референсы для ⚡ постов про фичи
- `case/` — референсы для постов про кейсы

Поддерживаются изображения (jpg/png/webp) — первое найденное изображение в папке
берётся как визуальный референс стиля при генерации картинки через Replicate
(автоматическая генерация в `autopost.ts`).

Сейчас во всех трёх папках лежит `02_totem_cover_horizontal.png` — референс
стиля маскота (чёрное худи, зелёная кепка, плоская иллюстрация). Замените или
дополните под конкретный тип поста, если нужен другой референс.

Видео-файлы (mp4) можно класть туда же — они пока не используются (шаг с
анимацией img2video ещё не подключён), но будут подхвачены автоматически,
когда эта функция появится.

Файлы должны быть закоммичены в репозиторий — GitHub Actions читает их из
чекаута при каждом запуске.

## `../assets/brand/`

Логотип и прочие точные бренд-активы, которые **не участвуют** в генерации
через Replicate — они пойдут в будущий детерминированный SVG/HTML-рендерер
(наложение точного текста и логотипа поверх иллюстрации).

## `../references/case-cards/`

Референсы карточек кейсов с перепиской (сетка, роли, отступы, блок результата)
— тоже не для text-to-image. Это чертёж для будущего рендерера карточек кейсов,
описанного в бренд-ТЗ (раздел про шаблон кейсов с перепиской).
