# LeadGet — стандарт карточек переписки для кейсов

Версия 1.0. Это обязательный production-стандарт для всех будущих кейсов LeadGet.

## 1. Формат и структура серии

- Формат каждого слайда: `1254 × 1254 px`, PNG, sRGB, `1:1`.
- Серия: обычно `4` слайда. Счётчик: `01 / 04`, `02 / 04`, `03 / 04`, `04 / 04`.
- Один слайд = один понятный этап диалога.
- Последовательность: 1) первый контакт; 2) выявляем интерес; 3) уточняем потребность; 4) передаём материалы/менеджеру.
- Нельзя смешивать на одном слайде два разных этапа, если из-за этого сообщения становятся мелкими или между ними возникает пустота.

## 2. Холст и базовая сетка — не менять

| Параметр | Значение |
|---|---:|
| Холст | `1254 × 1254 px` |
| Фон | `#F4F1EA` |
| Сетка | `42 × 42 px` |
| Линия сетки | `#D9D4CA`, opacity 30–40% |
| Внешнее поле | `64 px` |
| Чёрный | `#16120D` |
| Зелёный | `#1F7A3D` |
| Светлая плашка | `#F8F6F0` |
| Светлая обводка | `#D9D4CA` |

Сетка идёт по всему холсту. Никаких градиентов, теней, 3D, цветных фонов или дополнительных акцентных цветов.

## 3. Header — фиксированная геометрия

### Верхняя плашка

- Позиция: `x=64, y=58`.
- Размер: `260 × 54 px`.
- Радиус: `27 px`.
- Заливка: `#16120D`.
- Внутри: маленький зелёный маркер/иконка слева и label вида `КЕЙС · [НИША]`.
- Label: `JetBrains Mono Medium`, 13–14 px, верхний регистр, цвет `#F4F1EA`.

### Счётчик

- Правый край: `x=1190`.
- Базовая линия: около `y=93`.
- Шрифт: `JetBrains Mono Bold`, 14–16 px, цвет `#1F7A3D`.
- Только формат `NN / NN`.

### Заголовок этапа

- Позиция: `x=64, y=154`.
- Шрифт: `Unbounded Bold`, 30–34 px, `#16120D`.
- До 2 строк; предпочтительно 1 строка.
- Примеры: `Первый контакт`, `Выявляем интерес`, `Уточняем задачу`, `Передаём материалы`.

### Разделитель

- От `x=64` до `x=1190`.
- `y=218`.
- Толщина `2 px`, цвет `#D9D4CA`.

Нельзя менять положение header между слайдами.

## 4. Логика переписки — обязательна

- Бот всегда пишет справа.
- Собеседник всегда пишет слева.
- Каждый bubble обязан иметь маленький role label вверху.
- Роль бота: `ИИ-АГЕНТ · LEADGET` (или нейтрально `ИИ-АГЕНТ · СЕРВИС`).
- Роль собеседника: `СОБЕСЕДНИК`.
- Лейблы не заменяются именами клиентов/людей.
- Первый активный message на слайде может быть от бота, но сторона никогда не меняется.

## 5. Координаты и границы сообщений

### Бот

- Правая граница каждого bot bubble: `x=1190`.
- Минимальная ширина: `300 px`.
- Максимальная ширина: `760 px`.
- Внутренний padding: `28 px` слева/справа, `24 px` сверху/снизу.
- Фон: `#16120D`.
- Радиус: `26–30 px`.
- Текст: светлый `#F4F1EA`.

### Собеседник

- Левый край каждого client bubble: `x=64`.
- Минимальная ширина: `180 px`.
- Максимальная ширина: `680 px`.
- Внутренний padding: `28 px` слева/справа, `24 px` сверху/снизу.
- Фон: `#F8F6F0`.
- Обводка: `2 px #D9D4CA`.
- Радиус: `26–30 px`.
- Текст: `#16120D`.

### Вертикальный ритм

- Расстояние между двумя bubbles: `24–34 px`.
- Между логическими блоками: `40–56 px`.
- Не допускать одной плашки «в воздухе»: если рядом много пустоты, перераспределить сообщения вверх/вниз.
- Последнее сообщение должно заканчиваться минимум за `56 px` до линии блока результата.

## 6. Типографика внутри сообщений

| Элемент | Шрифт | Размер |
|---|---|---:|
| Role label | JetBrains Mono Medium | 11–12 px |
| Основной текст | Golos Text Medium | 20–23 px |
| Выделение цифр/ссылок | Golos Text Bold | 20–23 px |
| Результат — label | JetBrains Mono Medium | 13 px |
| Результат — title | Unbounded Bold | 20–24 px |
| Результат — copy | Golos Text Medium | 16–18 px |

Текст нельзя растягивать, наклонять, сжимать по ширине, писать произвольным шрифтом или превращать в рукописный. У каждого bubble расстояние от текста до края одинаковое: минимум `24 px`, визуально равное с обеих сторон.

## 7. Построение bubble — формула

1. Сначала разбить текст на строки естественной длины.
2. Выбрать ширину bubble так, чтобы слева и справа от самой длинной строки оставалось `28 ± 4 px`.
3. Добавить сверху role label, затем `12–16 px` до body text.
4. Добавить нижний padding `24–28 px`.
5. Не расширять bubble до максимума, если текст короткий.
6. Не сжимать bubble так, чтобы строки состояли из 1–2 слов.

Критическое правило: начало и конец каждой строки не должны «липнуть» к границам плашки; одинаковый запас с обеих сторон важнее идеальной симметрии плашек.

## 8. Блок результата — фиксирован

- Верхняя линия: `x=64…1190`, ориентир `y=900–930` (зависит от плотности сообщений, но не ниже `y=965`).
- Label: зелёный квадрат `10×10 px` + текст `РЕЗУЛЬТАТ ЭТАПА`.
- Title: внизу слева, сразу под label.
- Copy: одна короткая строка, объясняющая результат.
- В правом нижнем углу: большое бледное число слайда `01`, `02`, `03` или `04`, opacity 10–14%, цвет `#1F7A3D`.

Примеры результата:

- `Диалог начат` — «Собеседник вовлечён и задаёт предметный вопрос.»
- `Интерес подтверждён` — «Собеседник узнал условия и продолжил диалог.»
- `Потребность выявлена` — «Запрос и контекст для следующего шага понятны.»
- `Квалифицирован как лид` — «Интерес подтверждён, материалы переданы менеджеру.»

## 9. Анонимизация — обязательна

Внутри всех слайдов запрещены:

- название компании клиента;
- домен или сайт клиента;
- реальные имена, фамилии, @username;
- номер телефона, email, Telegram-ссылка;
- названия закрытых чатов и сообществ;
- сторонние лого.

Разрешено:

- «Меня зовут Нурлан, наша компания занимается SEO-продвижением.»
- «Ссылка на материалы: https://site.ru/».
- «Передам материалы менеджеру.»
- «Сервис по SEO-продвижению», «ИИ-агент для заявок», «образовательный центр».

В описании кейса и label верхней плашки использовать только обезличенную категорию: `SEO`, `ОБРАЗОВАНИЕ`, `E-COMMERCE`, `B2B-СЕРВИС`.

## 10. Что можно заменять

| Элемент | Можно заменить | Ограничение |
|---|---|---|
| Ниша в header | Да | Только обезличенная категория |
| Заголовок этапа | Да | До 2 строк |
| Номер слайда | Да | По порядку серии |
| Текст сообщений | Да | Стороны/роли сохраняются |
| Количество bubbles | Да | 3–6 на слайд, без пустот |
| Ширина/высота bubble | Да | Только по формуле отступов |
| Result title/copy | Да | Коротко, по сути этапа |

## 11. Что нельзя заменять

- Квадратный формат `1254×1254`.
- Кремовый фон и тонкую сетку.
- Чёрно-зелёную палитру.
- Header anchors, divider и общий ритм.
- Бот справа, собеседник слева.
- Тёмные bubbles бота и светлые bubbles собеседника.
- Role labels.
- Шрифтовую иерархию.
- Блок результата и большой бледный номер внизу справа.
- Правило равных внутренних отступов.

## 13. Финальный чек-лист

- [ ] 1254×1254, PNG, sRGB.
- [ ] Бот справа, собеседник слева.
- [ ] Role label есть у каждого bubble.
- [ ] Плашки не кривые, не растянутые; отступы вокруг текста равные.
- [ ] Нет анонимизационных ошибок.
- [ ] Шрифт только Unbounded, Golos Text и JetBrains Mono.
- [ ] Визуальный ритм плотный; нет одиноких bubbles и больших пустот.
- [ ] Внизу есть result block и большой бледный номер.
