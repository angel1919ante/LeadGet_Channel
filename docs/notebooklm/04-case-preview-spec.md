# LeadGet — горизонтальное превью кейса

Версия: 1.0
Базовый мастер: `1672 × 941 px`, PNG, sRGB, 16:9.
Назначение: обложка кейса для Telegram-поста. Это не фотография и не рекламный баннер в 3D: это строгая плоская редакционная инфографика.

## 1. Главный принцип

Карточка объясняет кейс за 2 секунды:

`заголовок → понятная схема процесса → 3 главные метрики → LeadGet`.

Никаких названий клиентов, доменов клиентов, реальных логотипов, персональных данных и узнаваемых продуктовых названий. Все кейсы обезличенные.

## 2. Холст и сетка — неизменяемые параметры

| Параметр | Значение |
|---|---:|
| Размер | `1672 × 941 px` |
| Соотношение | `16:9` |
| Фон | `#F4F1EA` |
| Внешнее безопасное поле | `64 px` слева/справа, `48 px` сверху/снизу |
| Сетка | квадрат `56 × 56 px` |
| Цвет сетки | `#D9D4CA` |
| Непрозрачность сетки | `28–35%` |
| Основной чёрный | `#16120D` |
| Акцентный зелёный | `#1F7A3D` |
| Белый | только внутри лица/бликов/светлых областей доски |

Сетка идёт по всему полотну. Она должна быть едва заметной: структурировать фон, а не становиться декоративным паттерном.

## 3. Строгая сетка композиции

Все координаты ниже относятся к холсту `1672 × 941`.

### 3.1 Заголовочная зона — фиксирована

- Левый край заголовка: `x=64`.
- Верх первой строки: `y=54`.
- Высота зоны заголовка: до `y=300`.
- Заголовок занимает максимум две строки.
- Между заголовком и подзаголовком: `18–24 px`.
- Подзаголовок начинается на `x=68`, ориентир по `y=279`.
- Не сдвигать заголовок в центр и не ставить его над доской.

### 3.2 Рабочая зона — фиксирована

- Маскот: нижний левый сектор, примерная зона `x=145…665`, `y=345…858`.
- Доска: правая центральная зона, внешняя рамка примерно `x=665…1518`, `y=318…762`.
- Логотип: нижний правый сектор, базовая зона `x=1198…1608`, `y=824…900`.
- Между низом доски и логотипом — минимум `28 px` свободного воздуха.

Нельзя:

- поднимать доску в заголовочную зону;
- ставить маскота по центру;
- растягивать доску до краёв;
- закрывать логотип предметами, ногами маскота или цифрами;
- оставлять огромную пустую середину композиции.

## 4. Типографика — фиксирована

### Заголовок

- Шрифт: `Unbounded Bold / 700`.
- Цвет: `#16120D`.
- Размер: `76–88 px`.
- Межстрочный интервал: `0.92–0.98` от кегля.
- Трекинг: `-2% … 0%`.
- Только верхний регистр для ключевых аббревиатур: `SEO`, `AI`, `B2B`, `TOP 10`.
- Не использовать широкий гротеск, рукописный шрифт или стандартный Arial/Inter для заголовка.

### Подзаголовок

- Шрифт: `JetBrains Mono Medium`.
- Цвет: `#1F7A3D`.
- Размер: `26–29 px`.
- Верхний регистр.
- Трекинг: `4–7%`.

### Цифры метрик

- Шрифт: `Unbounded Bold`.
- Размер: `50–58 px`.
- Цвет: `#1F7A3D`.
- Всегда пробел-разделитель тысяч: `2 431`, а не `2431`.

### Подписи к цифрам

- Шрифт: рукописный/маркерный только в рамках доски; внешний вид — аккуратная тёмно-зелёная ручная подпись.
- Размер: `28–33 px`.
- Цвет: `#1F7A3D`.
- Под каждой подписью — короткая зелёная подчёркивающая линия шириной `85–140 px`.

### Логотип

- Использовать только утверждённый исходный wordmark `LeadGet.`: чёрное слово и зелёная точка.
- Не перерисовывать буквы генеративной моделью.
- На данном размере ширина логотипа `360–410 px`.
- Правый край: `x=1608 ± 8 px`; нижний край: `y=900 ± 8 px`.

## 5. Маскот — фиксированная идентичность

Маскот неизменяемый. Использовать минимум два референса: один на пропорции и один на лицо.

### Что обязательно

- Большая зелёная кепка и голова: визуально около `65–70%` высоты персонажа.
- Компактное, низкое, мягкое тело.
- Только сидячая или низкая присевшая поза.
- Чёрный худи, зелёные шнурки, маленькая метка `L.` на груди.
- Чёрные брюки.
- Простые округлые чёрные кеды с белым контуром. Кеды небольшие: не массивнее `20%` ширины нижней части фигуры каждый. Никаких платформ, ботинок, Rick Owens-подобного силуэта.
- Толстые чёрные скруглённо-прямоугольные очки.
- Глаза спокойные, узкие, полуприкрытые. Никаких круглых распахнутых или радостных дуг.
- Маленький аккуратный нос и сдержанный рот.

### Что запрещено

- Робот, андроид, механические части.
- Высокая стоячая фигура, длинные ноги, вытянутое тело.
- Балаклава, маска, тёмное лицо.
- Круглые «кольца» вместо очков.
- Аниме-глаза, детская мимика, большая улыбка, зубы.
- 3D, реалистичная кожа, тени, градиенты, текстура бумаги, halftone.

### Поза в превью

Маскот сидит внизу слева, немного развёрнут к доске. Одна рука держит зелёный маркер и направлена на схему. Другая рука спокойно лежит у коленей. Его задача — объяснять, а не быть главным объектом кадра.

## 6. Доска — фиксированная конструкция

- Внешний прямоугольник с мягко скруглёнными углами.
- Белая/очень светлая кремовая заливка.
- Обводка `#16120D`, толщина `6–8 px`.
- Радиус угла `16–20 px`.
- Две короткие чёрные ножки по нижней кромке доски.
- Внутренние поля: минимум `56 px` слева/справа, `38 px` сверху/снизу.
- Доска не должна быть перспективной, объёмной, реалистичной или наклонённой.

## 7. Схема на доске

Всегда 3 шага в одной горизонтальной строке:

`источник/проблема → действие системы → результат`.

### Геометрия

- Центры трёх иконок: примерно `x=810`, `1080`, `1340` по общему холсту.
- Верхняя строка иконок: `y=430–500`.
- Между иконками — чёрная стрелка толщиной `7–9 px`, длиной `50–72 px`.
- Иконки одинаковой визуальной массы, размер `110–160 px`.
- Не делать больше трёх шагов.

### Что можно менять

Только смысл трёх иконок под кейс:

- источник: магазин, реклама, таблица, CRM, сообщения, сайт, заявка;
- действие: бот, документ, чат, аналитика, аудит, воронка;
- результат: карточка лида, галочка, рост графика, контакт, календарь, продажа.

### Что нельзя менять

- Горизонтальное направление слева направо.
- Количество шагов — ровно 3.
- Цветовую логику: источник обычно чёрный, действие и результат преимущественно зелёные.
- Стрелки не могут быть пунктирными, объёмными или декоративными.
- Не использовать реальные бренды/логотипы клиента и чужие интерфейсы.

## 8. Метрики на доске

Под схемой — ровно 3 метрики, каждая в своей колонке. Колонки одинаковой ширины и выровнены по центрам иконок.

### Рекомендуемый выбор трёх метрик

1. объём действия: `отправок`, `заявок`, `диалогов`;
2. целевой результат: `квал. лидов`, `встреч`, `аудитов`;
3. экономика или финальный результат: `контакт`, `квал. лид`, `продажи`.

На обложке нельзя размещать все показатели кейса. Проценты и подробную воронку оставлять в тексте поста или следующих слайдах.

## 9. Переменные поля для нового кейса

| Поле | Ограничение |
|---|---|
| Заголовок | До 2 строк, до 42 символов в строке; без названия клиента |
| Подзаголовок | Один короткий результат/аудитория, до 54 символов |
| Иконки схемы | Новые, но строго 3 и в той же структуре |
| 3 метрики | Новые цифры/подписи, одинаковый формат |
| Поза руки маскота | Только чтобы он логично указывал на новую схему |

Не менять: холст, поля, сетку, фон, палитру, шрифтовую иерархию, расположение заголовка, размер доски, размещение маскота, положение логотипа, общий стиль контуров.

## 10. Анонимизация — обязательна

На превью нельзя показывать:

- название компании-клиента;
- домен клиента;
- название продукта клиента, если по нему можно определить компанию;
- имена сотрудников/клиентов;
- номера телефонов, реальные Telegram-юзернеймы;
- скриншоты кабинетов или чужие лого.

Использовать нейтральные формулировки: `сервис по SEO-продвижению`, `ИИ-агент для входящих заявок`, `образовательный центр`, `производитель`, `интернет-магазин`.
