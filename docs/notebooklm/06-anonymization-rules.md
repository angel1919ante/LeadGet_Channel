# Анонимизация — обязательное правило, зафиксировано после реального инцидента

## Правило

Ни в тексте поста, ни на картинке (доска кейса, слайды переписки) не может появиться настоящее имя клиента, домен, реальные имена/фамилии/@username сотрудников, номера телефонов, ссылки на закрытые чаты. Разрешена только обезличенная категория ниши: SEO, ОБРАЗОВАНИЕ, E-COMMERCE, B2B-СЕРВИС, «сервис по SEO-продвижению», «ИИ-агент для входящих заявок» и т.п.

Это касается трёх мест одновременно:
- Текст поста (генерирует LLM по `casePostPrompt`)
- Доска-превью кейса (рисует `caseBoard.ts`, текст на картинке идёт verbatim из переданного `title`)
- Слайды переписки (рисует `caseChat.ts`, LLM пишет диалог по `caseChatPrompt`)

## Что произошло (15.08.2026) и как исправлено

`caseGen.ts` брал нишу кейса из поля `Данные.niche` в `ContentPlan`. Если это поле не было заполнено вручную, код тихо подставлял **настоящее название компании клиента**, полученное из LeadGet API (`fetchCampaignInfo`, поле `info.name`) — это и есть реальное имя клиента из его собственного кабинета. LLM в тексте поста обычно перефразировал это в общую формулировку, но на доске-превью название рендерилось буквально как есть — картинка с реальным именем клиента ушла в канал.

**Исправление:** `niche` теперь ОБЯЗАТЕЛЬНОЕ поле. Если `Данные.niche` не задано в `ContentPlan`, `generateCase()` выбрасывает ошибку вместо того, чтобы подставить реальное имя — пост просто не создастся, пока человек не впишет анонимизированную нишу руками.

**Практический вывод:** при создании кейс-поста (через таблицу или веб-панель) поле `Данные` обязано содержать `{"niche": "..."}` с анонимизированной формулировкой — например `{"niche": "агентство недвижимости"}`, а не `{"niche": "ООО Ромашка"}` и тем более не пустой JSON.

## Где искать эту логику в коде

`src/caseGen.ts` — функция `generateCase()`, блок проверки `if (!data.niche) throw ...`. `src/caseBoard.ts` и `src/caseChat.ts` сами по себе анонимизацию не проверяют — они рендерят то, что им передали, поэтому вся ответственность на входных данных из `caseGen.ts`.
