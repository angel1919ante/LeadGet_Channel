# Промпты и структура постов — текстовая часть

Источник истины в коде: `src/prompts.ts`. Ниже — то же самое человеческим языком, по каждому типу поста.

## Новость

**Логика — три обязательных слоя, пропустить нельзя:**
1. Новость — что случилось в мире/рынке
2. Экспертиза — что это значит для сферы и аудитории
3. LeadGet — почему именно с нами работать в этом контексте (не реклама, а логичный вывод из экспертизы; не начинается с «Именно поэтому LeadGet...»)

**Структура поста (строго):**
- 🔔 Заголовок — коротко, конкретно, без кликбейта
- Слой 1: 2-3 предложения — что случилось, цифры, источник
- 📊 Слой 2: заголовок блока + 3 пункта, что изменилось конкретно
- ⚠️ Вывод — что это значит для рынка/МСП
- Блок-цитата — ключевой факт отдельным абзацем
- ℹ️ Слой 3: позиция LeadGet, 2-4 предложения
- CTA — мягкий вопрос + «Напишите @LeadGet_info 📱»

**Эмодзи-маркеры:** ✔️ плюсы/подтверждение, ⚠️ риски, 📊 данные, 🔥 срочно, 💸 деньги, ⚡ быстрый результат, 💡 инсайт, ℹ️ пояснение/позиция LeadGet, ↗️ рост.

**Объём:** 800–1500 символов. Публикуется без фото.

## Кейс

**Логика:** Контекст (ниша клиента, задача, почему стандартные каналы не подходили) → Механика (что конкретно настроили) → Результат (цифры, конверсии, стоимость лида, сравнение с рынком).

**Структура:**
- 📊 Заголовок — «Кейс: ниша или тип задачи»
- Вводный абзац: 2-3 предложения
- 💡 База — откуда, сколько контактов, какой сегмент (масштаб — ключевая цифра)
- ⚙️ Что сделали — 4 пункта конкретных действий
- ↗️ Итоги за период — цифры блоком: отправлено / прочитали / ответили / квал. диалогов / конверсия в лид / цена лида
- Сравнение с рынком, если есть
- ✉️ CTA

**Объём:** 800–1500 символов. Идёт с доской-превью (детерминированный рендер) и альбомом из 4 слайдов переписки.

## Фича

**Логика:** Проблема (что раньше не работало) → Решение (что сделали, как работает) → Польза (конкретный результат для клиента, не технология ради технологии).

**Структура:**
- ⚡️ Заголовок — суть фичи в одной строке
- Вводный абзац: какая была проблема
- ⚙️ Что изменилось — 4 пункта
- Блок-цитата — «Раньше было X, теперь Y»
- Доп. контекст, если есть
- CTA — предложение попробовать + ссылка на сайт

**Эмодзи:** ✔️, ⭐️, 💡, 🎙, 💎, ⚙️. **Объём:** 800–1500 символов.

## Общие запреты для всех типов постов

- Длинное тире (—) — только запятая, точка или двоеточие
- Клише: «важно отметить», «уникальный», «инновационный», «революционный», «это не X, это Y»
- Размытые источники («эксперты считают») — только конкретные имена и цифры
- Раздутая значимость: «знаменует», «символизирует», «переломный момент»
- Причастные обороты на -ing (подчёркивая, отражая, демонстрируя)
- Правило трёх без необходимости, театральные паузы, рубленые фразы для драмы
- Заголовки-секции внутри поста («Что это значит», «Вывод», «Итого»)
- Слово «лид» в тексте к читателю — только «клиент»
- Повтор одного и того же эмодзи в посте; буллеты только через •
- Разрешены только эти эмодзи: 🔔 📊 ⚠️ ✔️ 💸 ⚡️ ⚡ 💡 ℹ️ 🛍 💎 📌 🎙 ⭐️ ⚙️ 📈 ✉️ 🔥 ↗️ 💰 🚀 📱 📉 🔴 🟢 💯 — все остальные под запретом
- 📱 используется только сразу после @LeadGet_info в CTA

## Оценка релевантности новостей (при сборе кандидатов)

- **8–10 (высокая):** конкретное обновление рекламной платформы с цифрами, новый инструмент для лидогенерации/атрибуции, исследование рынка с данными, Telegram-маркетинг
- **5–7 (средняя):** общие маркетинговые тренды с данными, смежные темы (e-commerce, retention)
- **1–4 (низкая):** корпоративные новости без данных, SEO-теория, ивент-анонсы, колонки мнений, HR, дизайн

## Саммари новости (простыми словами)

2-3 предложения на русском, как объяснение другу: что случилось и почему это важно для предпринимателя/маркетолога. Английские источники переводятся по смыслу. Без вводных фраз, без пафоса, без длинного тире.
