# Справочник таблиц и веб-панели

## Google Sheets — колонки по листам

**News:** Дата | Источник | Заголовок | Саммари | Пост | Ссылка | Рейтинг | Статус | Статья. Статус: `pending` / `approved` / `rejected` / `posted` / `error`.

**ContentPlan:** Дата | Тип | Заголовок | Токен | Данные | Статус | Пост | Ссылка. Тип: `новость` / `кейс` / `фича`. Статус: `draft` / `approved` / `posted` / `error`. Поле «Данные» — JSON: для кейса обязательно `{"niche": "..."}` (см. документ про анонимизацию), опционально `task`, `mechanics`, `price`, `boardTitle`, `boardSubtitle`; для фичи — `{"problem": "...", "description": "..."}`. Колонка «Ссылка» заполняется автоматически после публикации — прямая ссылка на пост в Telegram.

**Features:** Дата | Название | Проблема | Описание | Статус. Статус: `draft` / `approved` / `posted`.

**Cases:** Дата | Клиент | Токен | Ниша | Отправлено | Лиды | Конверсия% | Статус. Статус: `pending` / `approved` / `add to plan` / `posted` / `skip`.

**Preferences:** Обновлено | Источник | Всего | Одобрено | Отклонено | Рейтинг одобр. | Рейтинг откл. | Доверие | Порог (глоб.). Пишется только скриптом `learn.ts`, вручную не редактируется.

**AutoPosts:** служебный журнал публикаций, для дедупликации — не для ручного редактирования.

## Веб-панель (lead-get-channel.vercel.app)

Next.js-приложение на Vercel, читает/пишет те же Google Sheets напрямую (не через сам бот). Разделы:

- **Новости** — карточки pending-новостей с кнопками «Одобрить»/«Отклонить», видна релевантность.
- **Кейсы** — pending-кандидаты из Cases с метриками, «Одобрить»/«Пропустить».
- **Фичи** — список идей + форма добавления новой прямо из панели (название/проблема/описание), кнопка «Одобрить для плана».
- **План** — контент-план карточками, сгруппированными по неделям, с реальными данными (метрики кейса из Cases, проблема/описание фичи из Features, превью уже опубликованного текста), и кнопкой «Открыть» на реальный пост в Telegram, если он уже вышел.
- **Настройки** — объясняет логику бота человеческим языком: текущий порог релевантности (шкала 1-10 с объяснением), доверие к каждому источнику (светофор), полные тексты всех промптов (новость/кейс/фича + общие запреты + правила фото), и раздел «Формальные спеки» с дословным текстом `case-preview-spec.md`/`case-chat-spec.md` — с явной пометкой, реально ли эта спека используется в коде.

Панель — не альтернативный источник правды, а удобная надстройка над той же таблицей: изменения в панели сразу видны в Google Sheets и наоборот.
